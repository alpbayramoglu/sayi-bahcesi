# Sayı Bahçesi

6 yaş için matematik oyunu: toplama, çıkarma, sayı dizisi, boşluk doldurma ve karışık mod. Kolay (0–5), Orta (0–10), Zor (0–20) seviyeleri var. Sorular Türkçe sesli okunur, yanlış yapılan sorular aralıklı olarak tekrar gelir.

Derleme adımı yok. Yerelde denemek için: `python3 -m http.server 8000`

Her yayında `sw.js` içindeki `CACHE` adını artır (`sayi-bahcesi-v2` gibi); artırmazsan telefon eski sürümde kalır.

Yazı tipi: Baloo 2 (SIL OFL 1.1, `fonts/OFL-baloo2.txt`).
